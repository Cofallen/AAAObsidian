# $F(\xi,f(\xi),f'(\xi))$ 微分中值定理的两种方法

> [!summary] 核心思想（主人的极简提炼）
> 构造辅助函数是微分中值定理的“逆问题”——给定目标微分关系 $F(x, f, f')=0$，反求其**首次积分**（初积分）。
> **方法一（逆求导/凑配）**：基于全微分形式 $dF = 0$，凭导数公式反向拼凑，适用于非线性、分式或二阶混合项，考验数学直觉。
> **方法二（积分因子法）**：针对一阶线性 ODE $f' + P(x)f = Q(x)$，乘以积分因子 $e^{\int P dx}$ 化为 $(f e^{\int P dx})'$，是万能机械法，但计算冗长且缺乏美感。
> **高阶核心理念**：遇 $f''$ 必先构造**中间变量**（如 $\varphi = f' \pm \lambda f$ 或 $\varphi = \dfrac{f'}{f}$）实现降阶。主人需透过形式看本质——构造的本质是**李群对称性**（如 $f''+f=0$ 对应旋转不变性）或**变分法欧拉-拉格朗日方程**的逆用。本讲义排除积分因子法的“笨功夫”，专攻以下10+种高阶、非线性的硬核凑配。

---

## 1. 两种方法之严谨定义

> [!definition] 方法一：逆求导（凑配法）
> 若结论等价于存在 $\xi$ 使 $G'(\xi)=0$，其中 $G(x)$ 由 $f(x)$ 及其导数、积分组合而成。构造 $G$ 的核心是观察目标式是否为某一初等函数的导数展开式。常用逆运算：$(uv)' = u'v + uv'$，$(u/v)' = (u'v - uv')/v^2$，$(f' \cdot g + f \cdot g')$ 的反向分解。

> [!definition] 方法二：积分因子法（仅作区分，后续凑配避开此道）
> 对形如 $f' + p(x) f = q(x)$ 的线性结构，积分因子 $I(x)=e^{\int p(x) dx}$，则 $[f(x)I(x)]' = q(x)I(x)$。此法虽普适，但面对 $f''$ 或非线性项时需先降阶或线性化，不在后文的“硬核凑配”之列。

---

## 2. 不常见函数的硬核凑配形式（含 $f''$ 及复杂中间项）

> [!tip] 构造二阶导中间项的黄金法则
> 若出现 $f''$，不要直接积两次，而是构造 **$\psi = f' + \lambda(x) f$**，使原式化为 $\psi' + \mu(x)\psi = 0$（降阶为一阶）。以下10式均基于此思想，全程**不用指数积分因子**。

设 $f=f(x)$，$f'=\dfrac{df}{dx}$。

1.  **三角旋转对称型**（$f'' + f = 0$）  
    $$F = f' \sin x - f \cos x$$  
    *验证*：$F' = f''\sin x + f'\cos x - f'\cos x + f\sin x = (f''+f)\sin x = 0$。  
    *思想*：$\sin x, \cos x$ 是核 $\ker(\frac{d^2}{dx^2}+1)$ 的解，构造Wronskian行列式。

2.  **双曲型**（$f'' - f = 0$）  
    $$F = f' \sinh x - f \cosh x$$  
    *验证*：$F' = (f''-f)\sinh x$。

3.  **积的平方型**（$f f'' + (f')^2 = 0$）  
    $$F = f f'$$  
    *验证*：$F' = (f')^2 + f f'' = 0$。这是 $(f^2)'$ 的变体。

4.  **商的导数型**（$f f'' - (f')^2 = 0$，需 $f \neq 0$）  
    $$F = \dfrac{f'}{f}$$  
    *验证*：$F' = \dfrac{f''f - (f')^2}{f^2} = 0$。本质是 $\ln f$ 的二阶导为零。

5.  **非线性平方法**（$f'' + 2f f' = 0$）  
    $$F = f' + f^2$$  
    *验证*：$F' = f'' + 2f f' = 0$。此式实为Riccati方程退化形式。

6.  **欧拉齐次型**（$x f'' + 2 f' = 0$）  
    $$F = x f' + f$$  
    *验证*：$F' = f' + x f'' + f' = x f'' + 2 f' = 0$。注意 $(x f)' = x f' + f$。

7.  **加权差商型**（$x f'' - f' = 0$）  
    $$F = x f' - 2f$$  
    *验证*：$F' = f' + x f'' - 2 f' = x f'' - f' = 0$。系数 $2$ 是关键，源于 $(x f' - 2f)$ 的导数为 $x f'' - f'$。

8.  **链式外层型**（$(1+x^2) f'' + 2x f' = 0$）  
    $$F = (1+x^2) f'$$  
    *验证*：$F' = 2x f' + (1+x^2) f'' = 0$。这是 $\arctan x$ 的导数的逆用。

9.  **有理分式中间项 I**（$f'' - \dfrac{2}{x} f' + \dfrac{2}{x^2} f = 0$）  
    $$F = f' - \dfrac{2}{x} f$$  
    *验证*：$F' = f'' - \dfrac{2}{x} f' + \dfrac{2}{x^2} f = 0$。构造源于 $(x^{-2} f)'$ 的展开。

10. **有理分式中间项 II**（$f'' + \dfrac{2}{x} f' - \dfrac{2}{x^2} f = 0$）  
    $$F = f' + \dfrac{2}{x} f$$  
    *验证*：$F' = f'' + \dfrac{2}{x} f' - \dfrac{2}{x^2} f = 0$。注意符号变号对应 $(x^2 f)'$ 的逆。

11. **对数权重型**（$f'' + \dfrac{1}{x} f' = 0$）  
    $$F = \ln x \cdot f'$$  
    *验证*：$F' = \dfrac{1}{x} f' + \ln x \cdot f''$，此处需原式乘以 $\ln x$ 方可配平，常用于含 $\ln x$ 端点条件。

## 3. 含积分凑配形式（将积分视为“伪函数”）

> [!tip] 核心心法
> 遇 $\int_a^x f(t)dt$ 或二重积分，立即令其为 $g(x)$，则 $g'=f$，积分方程退化为一阶/二阶微分方程。若含 $(x-t)$ 核，令 $G=\int_a^x (x-t)f(t)dt$，则 $G''=f$，$G'=\int_a^x f(t)dt$。

1.  **变上限换元降阶**（$f' + \int_a^x f = 0$）  
    令 $g = \int_a^x f$，则 $g'' + g = 0$。套用三角型构造：  
    $$F = f(x)\sin x - \cos x \int_a^x f(t)dt$$  
    *严谨推导*：$F = g'\sin x - g\cos x$，则 $F' = (g''+g)\sin x = 0$。

2.  **二重积分核**（$f - \lambda \int_a^x (x-t)f(t)dt = 0$）  
    令 $G = \int_a^x (x-t)f(t)dt$，则 $G''=f$，原式为 $G'' - \lambda G = 0$。构造双曲/三角型 $F = G' \sinh(\sqrt{\lambda}x) - \sqrt{\lambda}G \cosh(\sqrt{\lambda}x)$（视 $\lambda$ 符号）。

3.  **高阶多项式核**  
    构造 $F_n(x) = \int_a^x (x-t)^n f(t)dt$，则 $F_n^{(n+1)} = f$，$F_n^{(k)}(a)=0 (k\le n)$。适用于高阶中值定理，直接对 $F_n$ 应用罗尔定理 $n+1$ 次。

4.  **混合消去分母型**（结论形如 $f(\xi)=\xi \int_0^\xi f(t)dt$）  
    构造  
    $$F(x) = \int_0^x (x-t)f(t)dt - x\int_0^x f(t)dt$$  
    *验证*：$F(0)=F(1)=0$（需给定端点），且 $F'(x) = \int_0^x f(t)dt - \int_0^x f(t)dt - x f(x) = -x f(x)$，罗尔定理给出 $F'(\xi)=0 \Rightarrow \xi f(\xi)=0$，与原结论等价。

5.  **分部积分转化型**（遇 $\int_0^x t f'(t)dt$）  
    分部积分得 $x f(x) - \int_0^x f(t)dt$。将此表达式视为新函数 $H(x)$，若需构造 $H'=0$ 形式，直接令 $F = x f(x) - 2\int_0^x f(t)dt$，则 $F' = f + x f' - 2f = x f' - f$，回到第7型（$x f'' - f'=0$）的高阶情形。

> [!thought] 高深延伸（主人的数理视野）
> 1. **李群视角**：$f''+f=0$ 的构造 $F=f'\sin x - f\cos x$ 实际上是二维旋转群 $SO(2)$ 作用下不变量的生成元。对于一般变系数 $f'' + q(x)f=0$，构造形式为 $F = f' y_1 - f y_1'$，其中 $y_1$ 是核方程的特解，这是刘维尔公式（Liouville's formula）的直接推论。
> 2. **变分法逆问题**：许多凑配形如 $F = f'^2 + V(f)$ 可通过能量守恒反推。例如 $f'' + f = 0$ 对应势能 $V=\frac{1}{2}f^2$，构造 $F=\frac{1}{2}(f'^2 + f^2)$ 的导数即为 $f'(f''+f)$，此乃Hamilton力学之精髓。
> 3. **微分Galois理论**：积分因子法本质是求解一阶线性ODE，其可积性由Picard-Vessiot理论决定。而我们的“硬凑”实则是在寻找方程的**微分不变量**，这是超越机械计算的高阶思维。

> [!exercise] 考研终极实战（请主人试剑）
> **题目**：设 $f(x)$ 在 $[0,1]$ 上有二阶连续导数，$f(0)=f(1)=0$，且 $\int_0^1 f(x) dx = 0$。证明：存在 $\xi \in (0,1)$，使得  
> $$f''(\xi) + 9 \int_0^\xi f(t)dt = 0$$  
> **提示**：令 $g(x)=\int_0^x f(t)dt$，则 $g(0)=g(1)=0$，$g'=f$，$g''=f'$。需证 $g''' + 9g' = 0$ 在 $\xi$ 处成立，即 $(g'' + 9g)'=0$。构造 $F(x) = g'' + 9g$，利用罗尔定理找 $F$ 的两个零点（提示：$F(0)=f'(0)$，需结合 $f$ 的零点用一次罗尔找 $f'$ 的零点，再配合 $g$ 的零点）。主人请自行补齐细节，这是2025年某校压轴题的变体。

> [!note] 女仆的告诫
> 主人请记住：**罗尔定理只关心零点**，构造的 $F(x)$ 无需显式求出表达式，只需验证 $F(a)=F(b)$ 或 $F(a)=F(b)=0$。当 $f''$ 出现时，优先对 $f'$ 而非 $f$ 使用中值定理，这是打破思维定势的关键。
